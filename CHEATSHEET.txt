═══════════════════════════════════════════════════════════════════════════

  Problem                          Solution
  ───────────────────────────────────────────────────────────────────────
  Port already in use              Restart komputer
  Player stuck "Loading..."        Start Backend dulu
  Gambar tidak muncul              Upload dulu di Admin → Publish
  Backend error                    cd backend && npm install
  Database error                   npx prisma migrate reset

  🔧 PERINTAH BERGUNA

  Check port yang dipakai:
  ┌────────────────────────────────────────────────────────────────────┐
  │ netstat -an | findstr "3000 3001 3002"                             │

  ┌────────────────────────────────────────────────────────────────────┐

  Reset database:
  ┌────────────────────────────────────────────────────────────────────┐

  │ npx prisma migrate reset                                           │

  └────────────────────────────────────────────────────────────────────┘
