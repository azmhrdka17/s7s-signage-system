🚀 CARA MENJALANKAN (PILIH SALAH SATU):
================================================================================

CARA 1: OTOMATIS (TERMUDAH)
---------------------------
1. Buka Command Prompt (CMD)
2. cd c:\s7s-signage-system
3. setup-all.bat         (sekali saja, untuk install)
4. start-all.bat         (untuk jalankan sistem)

CARA 2: MANUAL
--------------
Buka 3 jendela PowerShell terpisah:

[Jendela 1 - Backend]
cd c:\s7s-signage-system\backend
npm install
npx prisma generate
npx prisma migrate dev --name init
npm run prisma:seed
npm run start:dev

[Jendela 2 - Admin]
cd c:\s7s-signage-system\frontend-admin
npm install
npm run dev

[Jendela 3 - Player]
cd c:\s7s-signage-system\web-player
npm install
npm run dev
